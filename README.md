# オクターブ伸長の実験アプリ（調整法）

低い音（標準音）の「ちょうど1オクターブ上」に聞こえる高さを、調整法で探し、物理的なオクターブ（周波数が2倍）からのずれ（オクターブ伸長）を調べる、スマホ用の静的Webアプリです（`index.html` 1枚のみ、外部ライブラリなし）。Ward (1954) などの実験の簡易版です。

## 公開URL
（未設定）

## 機能
- 標準音の周波数：500／1000／2000 Hz から複数選択（初期値：500 Hz と 2000 Hz の2つ）
- 調整法：低い音（標準音）と、高い音（調整する音）が、この順に繰り返し鳴る。スライダーとボタン（−大／−小／＋小／＋大）で、高い音の高さを変え、「ちょうど1オクターブ上」に聞こえたら「決定」する。数値は表示されない
- 高い音の初期位置は、物理的オクターブ（標準音の2倍）の −5% または +5%（低い方から、高い方から）。試行の順序はランダム。試行数は、周波数の数 × 2（初期位置）× 2回（初期値で8回・約3分；3つ選ぶと12回・約4分）
- 純音の大きさは、ISO 226（40 phon）の曲線で、ほぼ等ラウドネスにそろえている（音量の違いが、高さの判断に影響しないようにするため）
- 結果画面：最初に、標準音ごとの結果（1オクターブ上に聞こえた高さが何倍か、2倍からのずれ（%）、セント）をまとめて表示し、そのあと、周波数とずれのグラフ（試行ごとの点と平均）を表示。物理的オクターブの位置を点線で示す
- 結果をCSV形式でコピーできる（授業での集計用）
- 音量あわせ（1000 Hz の音）のボタンがある

## 授業用のURL設定
なし（標準音の周波数は、画面上で選ぶ）。

## 使用上の注意
- 音量あわせをしてから始め、途中で端末の音量を変えない。イヤホン（ヘッドホン）を推奨する
- 簡易版なので、試行数が少なく、結果は大きくばらつく。伸長の大きさには個人差が大きく、ほとんど伸長しない人や、逆向きの人もいる
- 先行研究では、伸長の平均は約20セント（約1.2%）で、周波数が高いほど大きい（大串 2019、図6-4）
- iPhone はマナーモードを解除し、Safari で開く
- 画面を離れると、音は自動で止まる
